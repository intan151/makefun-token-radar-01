How the implied value is built

implied value = TVL × comps multiple × growth factor × maturity factor × chain factor

  • Comps multiple. The median market-cap / TVL of the protocols that already trade, in the same category, read from this very snapshot — never a list of names. A sector the market already prices richly prices a launch richly. Categories with fewer than 3 live tokens use the snapshot-wide median.
  • Growth factor. 1 + clamped 7-day TVL change (−50% to +150%) × 0.6.
  • Maturity factor. 0.7 + up to 0.3 for up to 3 years tracked with no token (unknown age counts as 365 days).
  • Chain factor. 1 + 0.03 per extra chain, up to 4 extra chains.
